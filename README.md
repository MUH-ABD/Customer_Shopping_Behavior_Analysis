# Customer Shopping Behavior Analysis

## Project Overview

This project analyzes customer shopping behavior using transactional data to identify spending patterns, customer segments, product preferences, subscription behavior, and other valuable business insights.

The analysis follows an end to end data analytics workflow using Python for data cleaning and preparation, PostgreSQL for SQL based analysis, and Power BI for data visualization and reporting.

## Dataset Summary

The dataset contains:

* 3,900 customer purchase records
* 18 columns

The dataset includes information related to:

* Customer demographics
* Age
* Gender
* Location
* Subscription status
* Purchased items
* Product categories
* Purchase amount
* Season
* Size and color preferences
* Discount usage
* Purchase frequency
* Previous purchases
* Review ratings
* Shipping type

The dataset initially contained missing values in the `Review Rating` column.

## Project Workflow

The project was completed in the following stages:

### 1. Data Cleaning and Preparation using Python

The dataset was processed using Python and Pandas.

The main steps included:

* Loading and exploring the dataset
* Checking data types and summary statistics
* Identifying missing values
* Handling missing values in the `Review Rating` column
* Filling missing review ratings using the median rating of each product category
* Renaming columns into snake case for better readability
* Creating new features for analysis
* Checking data consistency
* Removing redundant columns

### Feature Engineering

Two additional features were created:

* `age_group`, created by grouping customers according to their age
* `purchase_frequency_days`, created from purchase frequency information

The `promo_code_used` column was also identified as redundant with discount related information and removed from the dataset.

## Database Integration

After cleaning the dataset, Python was connected to PostgreSQL using SQLAlchemy.

The cleaned DataFrame was then loaded into PostgreSQL for further analysis using SQL.

## SQL Business Analysis

The following business questions were analyzed using PostgreSQL:

### 1. Revenue by Gender

Compared the total revenue generated by male and female customers.

### 2. High Spending Discount Users

Identified customers who used discounts but still spent more than the average purchase amount.

### 3. Top 5 Products by Rating

Identified products with the highest average customer review ratings.

### 4. Shipping Type Comparison

Compared average purchase amounts between Standard and Express shipping.

### 5. Subscribers vs Non Subscribers

Compared customer spending and total revenue based on subscription status.

### 6. Discount Dependent Products

Identified products with the highest percentage of discounted purchases.

### 7. Customer Segmentation

Customers were classified into the following groups:

* New Customers
* Returning Customers
* Loyal Customers

The segmentation was based on customer purchase history.

### 8. Top Products per Category

Identified the top 3 most purchased products within each category.

### 9. Repeat Buyers and Subscriptions

Analyzed whether customers with more than 5 previous purchases were more likely to have a subscription.

### 10. Revenue by Age Group

Calculated the total revenue contribution of different customer age groups.

## Power BI Dashboard

An interactive dashboard was created in Power BI to present the analysis and business insights visually.

The dashboard helps stakeholders understand:

* Customer spending behavior
* Revenue trends
* Customer demographics
* Product performance
* Subscription behavior
* Purchase patterns
* Customer segments

## Business Recommendations

Based on the analysis, the following recommendations were made:

### Increase Subscription Adoption

Promote exclusive benefits and offers to encourage more customers to become subscribers.

### Develop Customer Loyalty Programs

Reward repeat customers and encourage them to move into the Loyal Customer segment.

### Review Discount Strategy

Balance the benefits of discounts with profit margins to avoid excessive dependency on promotional offers.

### Improve Product Positioning

Highlight highly rated and frequently purchased products in marketing campaigns.

### Use Targeted Marketing

Focus marketing efforts on high revenue age groups and customers who prefer Express shipping.
